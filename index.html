Letter Pop: Fun Word Puzzle

Sole programmer. Unity, iOS and Android. July to October 2025, SnapJoy Games.

Players pull letter characters off a board to spell target words before the holding tray fills up. I wrote all the game code. A game designer built the levels, and an artist handled art, VFX and UI layout.

Gameplay

Board, letter units and navigation, word completion, dispensers and pipes, boosters, and a tutorial.

Level tools

A custom level editor and pipe editor, so the designer could build levels without code.

Systems

Level generation from the GDD, saves, audio, haptics, menus, and a small MVVM layer for UI.

Release

Store builds, A/B tests and optimization, with AppsFlyer, AppMetrica, Facebook, Adjust and AppLovin MAX integrated.

Derailed

Head Developer and Project Manager. Unity 6, URP, PC. In development since December 2025.

A story-driven, single-player sim with body horror. The player is an occult doctor on a hospital train, crossing a country torn by war and a supernatural epidemic. At each station you diagnose occult illnesses and operate through tactile mini-games.

I lead the team and the technical direction at SnapJoy Games, where the team page lists me as Bogdan Goncharov. Since the October 2026 rebuild, gameplay code is written with Claude Code under my direction and review.
